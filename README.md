# 京バスノート

京都のバス乗車記録と進捗地図を目指す試作です。デモ画面は架空路線だけを表示し、入力内容やグループ情報は保存しません。Supabase向けの認証画面、初期スキーマ、行単位のアクセス制御を作成しましたが、実プロジェクトにはまだ接続・適用していません。認証後も公式路線データが準備されるまでは記録や共有を使えません。

## はじめかた

Node.js と npm を用意したあと、依存関係を入れてデモを起動します。

```powershell
npm ci
npm run dev
```

ターミナルに表示されたローカル URL をブラウザーで開いてください。デモの背景地図には OpenFreeMap の公開タイルを使うため、地図の表示にはインターネット接続が必要です。路線形状と停留所名はすべて試作用の架空データです。

## 開発・確認コマンド

```powershell
npm test
npm run test:e2e
npm run lint
npm run build
```

## 継続的検査

GitHub Actionsでは、Node.js 22で依存関係を固定し、単体試験・lint・本番ビルド・Chromiumブラウザー試験を順に実行します。ブラウザー試験はローカルの試験スタイルと公式GTFS加工済みカタログだけを使い、公開の地図タイルや外部認証サービスには接続しません。

ブラウザー試験で Chromium がまだ用意されていない場合は、次を一度実行してください。

```powershell
npm exec playwright install chromium
```

ブラウザー試験はローカルの簡易地図スタイルを使い、試験中の HTTPS 通信を遮断します。認証試験もローカルの偽APIだけを使い、実Supabaseや公開の地図タイルには接続しません。試験用スタイルは `public/fixtures/test-style.json`、画面と認証の試験は `tests/e2e/`、距離集計と SVG 生成の単体試験は `src/domain/` にあります。

`npm run dev:test` はブラウザー試験用です。`npm run dev:configured` はSupabase設定を使います。`.env.local`にURLとpublishable keyを設定するとログイン・新規登録が実際のプロジェクトへ接続するため、接続先を確認してから操作してください。まだ認証後の乗車記録や共有は有効ではありません。`.env.example` は設定名の見本です。secret/service-role keyやODPT API keyをブラウザーへ渡したり、ソース管理へ入れたりしないでください。

## 画面とデータ

- 地図画面: 路線一覧、進捗状態での絞り込み、デモ用の路線地図、ベクター SVG のダウンロード。
- 記録画面: デモ用の日付・路線・停留所入力。路線を変えるとその路線の停留所候補に切り替わります。保存した乗車記録はブラウザーのlocalStorageに残り、地図の進捗と履歴へ反映します。クラウド同期と他端末共有は未接続です。
- グループ画面: 架空メンバーの距離表示。招待・同期やプライバシー制御は未接続です。
- `src/data/demoRoutes.ts`: 動作確認用の架空の路線形状・停留所・距離。実在する交通データではありません。
- `src/data/official-routes.json`: 京都バスと京都市営バスの提供GTFSから生成した静的路線カタログ。194路線を収録しています。
- `scripts/import_gtfs.py`: ローカルのGTFS展開フォルダーから静的カタログを再生成するスクリプトです。

SVG は路線と進捗をベクターで描き、背景地図は含みません。画面の地図タイルを SVG にコピーしないため、SVG 内の地図帰属表示は背景なしであることとデモ用データであることを示しています。

## 地図・データの出典と帰属

デモ画面の背景地図は [OpenFreeMap](https://openfreemap.org/) の Positron スタイル（`https://tiles.openfreemap.org/styles/positron`）です。地図上に表示される帰属表示を隠さないでください。スタイルとタイルに関する OpenMapTiles および OpenStreetMap の帰属は地図上の表示に従います。利用条件を確認せずに、タイルや地図画像を再配布しないでください。

試作データは作者が作った架空データで、京都市営バス・京都バスを含むいずれの事業者の公式データでもありません。ODPTの京都市営バスのリソースページでは、`Kyoto_City_Bus_GTFS_2026_0012_04`（有効期間: 2026-10-27〜2027-03-31）を確認しました。京都バスのリソースページとともに、公共交通オープンデータ基本ライセンスを案内しています。

2026-11-21に[基本ライセンス](https://developer.odpt.org/terms/data_basic_license.html)、[センター利用規約](https://developer.odpt.org/terms/center_use_rules.html)、[開発者ガイドライン](https://developer.odpt.org/terms/data_basic_use_guideline.html)を確認しました。登録が必要で、条件の範囲内なら営利・非営利のプロダクトで使えますが、元データの意味と内容を正確に反映し、更新に追随すること、元データや復元可能な加工データを原則再配布しないことなどが定められています。静的データを利用者に表示する場合は取得日時を画面から確認できるようにし、更新通知から1週間以内を目安に更新します。成果物を公開する際にはODPTを出典とする表示、正確性・完全性の免責、開発者の問い合わせ先も必要です。各事業者の特定利用条件と、このアプリでの加工・クラウド保管・SVG出力に当てはまる条件はまだ特定できていません。ライセンスへのリンクは[京都市営バスのODPTカタログ](https://ckan.odpt.org/dataset/kyoto_municipal_transportation_kyoto_city_bus_gtfs)と[京都バスのODPTカタログ](https://ckan.odpt.org/dataset/kyoto_bus_all_lines)から確認できます。GTFSはダウンロード・同梱していません。個別条件の確認が済むまで公式データを取り込んだり公開したりしないでください。

確認した特定利用条件本文は、東急バス、ANA、東京臨海高速鉄道、ゆりかもめ、東京メトロ等の画像データに関する追加条件で、京都バス・京都市交通局への個別条項は見当たりませんでした。ただし、これは京都のカタログページに事業者固有条件が別掲載されている可能性を否定したものではありません。京都のリソースごとの特定利用条件を事業者が公式に確認できるまで、本アプリの公式GTFS表示とSVGは公開しません。

## データベースのプライバシー基盤

`supabase/migrations/20261121000000_initial.sql`にはプロフィール、グループ、参加者、個人の乗車記録とRLSポリシーがあります。Supabase Authのユーザー作成時に、`display_name`メタデータから本人専用プロフィールを作ります。乗車記録は本人だけが読め、グループメンバーにはRPC経由で個人別の合計距離だけを返す設計です。メンバー一覧テーブルへのクライアント直接アクセスは許可していません。

`src/data/rideStore.security.test.ts`はPGlite上でプライバシーとプロフィール作成の試験を実行します。これはPostgreSQL互換エンジン上で`auth.uid()`を模擬した試験で、実際のSupabase Auth、PostgREST、リモート設定での動作を証明するものではありません。マイグレーションはまだSupabaseへ適用していません。

現状、距離は乗車記録の作成者が送る値を集計しています。信頼済み路線カタログとの照合やサーバー側での距離再計算は未実装なので、グループの合計値を検証済みの実績として扱わないでください。

## 技術とライセンス

画面は React、TypeScript、Vite、MapLibre GL JS で構成しています。進捗集計と SVG 作成は UI から分けた純粋な処理として実装し、UI は実際のブラウザーで確認します。

このプロジェクト自体は `package.json` で `UNLICENSED` としています。依存ライブラリはそれぞれのライセンス条件に従います。実在の路線データを加える場合は、ソースのライセンス・帰属条件を別途確認してから扱います。

## まだ実装していないもの

公式路線網の網羅、クラウドへの乗車記録同期、グループ招待、端末バックアップ、実データに基づく完全なSVGは未実装です。デモ画面では京都バス・京都市営バスのGTFSから生成した194路線カタログを表示し、ブラウザーのlocalStorageに記録・履歴・進捗を保存できます。Supabase認証画面と接続コードはありますが、実プロジェクトでの認証・RLS検証は未実施です。Supabaseプロジェクトも未設定です。事業者ごとの個別利用条件確認、独立した受け入れ評価、本番デプロイも未実施です。京都バスの提供版は2026-11-25、京都市営バスは2026-11-10の版です。この試作を実際の乗車記録や他人との共有に使わないでください。
